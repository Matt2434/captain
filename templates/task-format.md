# Task Format — DAEN 690 Scrum Board Standard
Source: instructor's "Task Format Instructions" template card (YouTrack 01A-3), synced 2026-08-26.

## Description
In Agile Scrum, tasks are small, actionable units of work created by breaking down a User Story into the specific activities required to deliver its outcome. A task description should state *what* needs to be done and *why*, expressed as a brief, clear narrative that explains the intent and scope of the work without prescribing exact implementation details. Each task should represent a coherent, meaningful piece of work that moves the team closer to completing the User Story and should be sized so that a team member can complete it within **one to three days**, reflecting standard Scrum practice for sprint-level planning. The description should allow any team member to understand the purpose of the task and pick it up independently, ensuring clarity, accountability, and traceability back to the User Story.

## Exit Criteria
Exit Criteria define the measurable conditions that indicate a task is fully complete, serving as the team's internal "definition of done" for that piece of work. Each criterion should be objective, verifiable, and expressed as a short checklist confirming that all required outputs, updates, reviews, or integrations have been completed. Industry practice recommends **three to six** exit criteria per task — enough to ensure clarity without unnecessary granularity. Well-written exit criteria eliminate ambiguity, support consistent quality, and help the team confirm that the task contributes to the User Story's acceptance criteria and the sprint goal before it is marked as done.

In YouTrack, Exit Criteria must be entered as a **checklist** (checkbox list), not bullets:
* [ ] Exit Criteria #1
* [ ] Exit Criteria #2
* [ ] Exit Criteria #3
* [ ] Exit Criteria #4

Workflow: tasks start Open → In Progress when work begins → To Verify when the assignee believes it complete → a **different** team member independently verifies by checking off each exit-criteria checklist item → only then Done.
